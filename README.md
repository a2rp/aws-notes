# AWS Study Notes

These are my personal study notes on Amazon Web Services, collected while learning cloud infrastructure and working through practical examples. They explain core AWS services, how the pieces connect, and the decisions I want to remember when building and operating workloads.

## Scope

The notes move from cloud fundamentals and account security into networking, compute, storage, databases, serverless applications, containers, messaging, observability, infrastructure as code, reliability, and cost management. Examples use AWS CLI commands, JSON policies, and infrastructure configuration to connect each idea to practical work.

AWS services and console screens change over time. Use the linked AWS documentation to verify current service behavior, limits, and pricing before applying a pattern to a real environment. Keep experiments in a sandbox account and remove resources when finished.

## How I use these notes

I keep these notes as a learning record. Read the chapters in order for a foundation, or open a topic directly when revisiting a service. Each chapter is intended to explain the reason behind a service, show how it works, and connect it to a small practical exercise. The final chapters collect code samples and review questions from across the notes.
